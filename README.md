# GENESIS — лаборатория воплощённого обучения

GENESIS — интерактивная лаборатория, в которой искусственный персонаж осваивает движение с нуля, а пользователь наблюдает не только за телом, но и за работающей нейросетью.

Это не заранее записанная анимация. Персонаж находится в физической симуляции: сеть получает сенсорные данные, выдаёт управляющие сигналы суставам, получает последствия своих действий и постепенно улучшает управление.

## Что должно происходить на экране

- Персонаж начинает с неумелых движений и падений.
- Через обучение осваивает контроль тела: перевороты и попытки подняться, удержание равновесия, первые шаги, устойчивую ходьбу и более быстрый бег.
- Рядом отображается реальная сеть управляющей политики: активность нейронов, сила и знак весов, сигналы между слоями и изменения параметров во время обучения.
- Графики показывают прогресс: время в вертикальном положении, пройденное расстояние, скорость, падения, энергозатраты и стабильность походки.
- Можно поставить обучение на паузу, замедлить симуляцию, выбрать нейрон и проследить его вклад в текущий управляющий сигнал.

## Принципы

1. Физика прежде анимации: суставы, контакты с землёй, силы и падения рассчитываются физическим движком.
2. Никаких поддельных нейронов: визуализация читает веса и активации из той самой сети, которая управляет телом.
3. Обучение без готовой походки: базовый эксперимент не использует motion-capture и готовую анимацию ходьбы.
4. Проверяемые результаты: улучшение подтверждается метриками и повторяемыми тестами.
5. Не путать обучение и эволюцию: PPO обучает параметры политики в течение запуска. Эволюция топологии — появление и удаление нейронов и связей — отдельный исследовательский режим.

## Техническая основа

- MuJoCo — физика многосуставного тела и контактов.
- Gymnasium — стандартный интерфейс среды обучения.
- PyTorch + Stable-Baselines3 (PPO) — обучение управляющей политики с нуля.
- FastAPI + WebSocket — передача состояния симуляции, метрик и нейронной активности.
- React + TypeScript + Vite + Three.js — интерактивная визуализация персонажа и нейросети.

Симуляция и обучение выполняются локально. Для первого прототипа ориентируемся на CPU и небольшую модель; скорость обучения будет зависеть от процессора и числа параллельных сред.

## Этапы разработки

1. Физическое тело и датчики.
2. Первые попытки движения: PPO, старт из лежачего положения, curriculum от подъёма к балансу и движению.
3. Наблюдаемая нейросеть: реальные активации и веса actor-сети, временная шкала сигналов, инспектор нейрона.
4. Сохранение и воспроизведение: контрольные точки обучения, повтор эпизода и сравнение версий политики.
5. Эволюционный режим: эксперимент с NEAT-подобным изменением топологии и отбором архитектур.

## Локальный запуск (Windows 10/11)

Нужны Python 3.11 и Node.js 20 или новее. В папке проекта открой два терминала.

Терминал 1 — виртуальное окружение и backend:

```powershell
py -3.11 -m venv .venv
.venv\\Scripts\\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python -m uvicorn genesis.server:app --host 127.0.0.1 --port 8000
```

Терминал 2 — frontend:

```powershell
npm install
npm run dev
```

Открой адрес, который покажет Vite (обычно http://127.0.0.1:5173). Обучение запускается из интерфейса; API доступен только на локальном компьютере.

Первый этап пока экспериментальный. Начинай с небольшого числа шагов, проверь стабильность физической модели и только потом увеличивай длительность.

## Ограничения интерпретации

Активации нейросети показывают вычисления модели, а не буквальные мысли или сознание. Успешная походка не доказывает возникновение общего интеллекта. GENESIS исследует воплощённое обучение и нейроэволюцию в ограниченной симуляционной задаче.
