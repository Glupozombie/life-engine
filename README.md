# LIFE ENGINE

Визуальный симулятор искусственной жизни и эволюции. Цель проекта — дать игроку возможность наблюдать за организмами, которые ищут ресурсы, размножаются, наследуют признаки, мутируют, адаптируются и вымирают, при этом понимать, почему мир меняется.

> **Важно:** документы описывают целевое направление и правила работы. Фактическое состояние функций нужно сверять с исходным кодом и отмечать в `docs/CURRENT_STATE.md`.

## С чего начинать ИИ-агенту

1. Прочитать [AGENTS.md](AGENTS.md).
2. Проверить [текущее состояние](docs/CURRENT_STATE.md).
3. Посмотреть ближайшие задачи в [дорожной карте](docs/ROADMAP.md).
4. При изменении игрового опыта свериться с [видением проекта](docs/PROJECT_BRIEF.md).
5. Перед правками изучить реальный код. Не переписывать приложение вслепую.

## Текущий статус

Документация создана как стартовая система передачи контекста. Полный технический аудит кода ещё не подтверждён. Сначала установить фактический стек, команды запуска, архитектуру и состояние сохранений; затем обновить документацию по результатам.

## Архивы проекта

Git хранит исходный код и историю изменений. Большие ZIP-архивы и сборки предпочтительно размещать в [GitHub Releases](https://github.com/Glupozombie/life-engine/releases), а не коммитить в историю исходников. В репозитории оставлять метаданные, инструкции и ссылки.
