# GENESIS — лаборатория воплощённого обучения

GENESIS — интерактивная локальная лаборатория, в которой двуногое физическое тело учится управлять движением через взаимодействие с симулятором MuJoCo. Пользователь наблюдает одновременно физику, процесс обучения и реальную нейросеть, управляющую суставами.

Это не заранее записанная анимация. Политика получает сенсорные наблюдения, выдаёт управляющие воздействия, получает последствия действий и обучается методом reinforcement learning.

## Текущий статус

Первый реализуемый этап — **stand/recovery**: базовое восстановление и удержание вертикального положения. Текущая реализация — ранний исследовательский прототип. Успешное обучение, освоенная ходьба и бег пока не подтверждены воспроизводимыми метриками на нескольких seed. Не следует воспринимать наличие задач `walk`/`run` в коде как доказательство освоенного навыка.

## Что должно происходить на экране

- Персонаж двигается в реальной физической симуляции, а не проигрывает готовую анимацию.
- Рядом отображается та же управляющая policy, которая влияет на тело: реальные активации и веса actor-сети.
- Метрики показывают измеримый прогресс: устойчивость, время до падения, наклон, скорость, reward и энергозатраты.
- Пользователь может запускать и останавливать эксперимент и видеть состояние backend/телеметрии.
- Отсутствующие данные должны показываться как отсутствующие, без имитации.

## Принципы

1. Физика прежде анимации: суставы, контакты, силы и падения рассчитываются MuJoCo.
2. Никаких поддельных нейронов: визуализация читает данные той же сети, которая управляет телом.
3. Обучение без готовой походки: базовый эксперимент не использует motion-capture как подмену обучения.
4. Проверяемые результаты: улучшение подтверждается метриками и повторяемыми тестами.
5. Не путать обучение и эволюцию: PPO обучает параметры политики; эволюция топологии — отдельный будущий эксперимент.
6. Не приписывать сети сознание или буквальные мысли.

## Техническая основа

- MuJoCo — физика многосуставного тела и контактов.
- Gymnasium — стандартный интерфейс среды обучения.
- PyTorch + Stable-Baselines3 (PPO) — обучение управляющей политики.
- FastAPI + WebSocket — API и передача телеметрии.
- React + TypeScript + Vite + Canvas 2D — визуализация тела и нейросети.

## Установка и запуск

Полная инструкция для Windows 10/11 и основных Linux-дистрибутивов: [docs/INSTALL.md](docs/INSTALL.md).

Краткий запуск Windows (Python 3.11, Node.js 20+).

Терминал 1 — backend:
```powershell
py -3.11 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python -m uvicorn genesis.server:app --host 127.0.0.1 --port 8000
```

Терминал 2 — frontend:
```powershell
npm install
npm run dev
```

Открой `http://127.0.0.1:5173/`. API docs: `http://127.0.0.1:8000/docs`.

Известные проблемы конкретной Windows-среды и подтверждённые обходные команды записаны в [AI_HANDOFF.md](docs/AI_HANDOFF.md). Не считать их исправленными без проверки.
