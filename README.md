# LIFE ENGINE

Визуальная браузерная песочница искусственной жизни. Организмы двигаются, ищут пищу, тратят энергию, размножаются, наследуют признаки с мутациями и конкурируют за ограниченные ресурсы. Цель — наблюдать за развитием экосистемы и понимать причины изменений без знаний биологии.

## Текущий статус репозитория

Исходное приложение пока хранится в архиве [`project-archive/life-engine.zip`](project-archive/life-engine.zip), а не в виде отдельных исходников в корне Git. Поэтому обычный diff и CI пока не охватывают код игры. Это следующий приоритет: [Issue #1 — перенести исходники в Git и настроить проверки](https://github.com/Glupozombie/life-engine/issues/1).

По архиву подтверждены проверка целостности ZIP и синтаксическая проверка четырёх JavaScript-модулей через Node.js. Полноценный браузерный E2E, сохранения после перезапуска и производительность ещё не проверены.

## Как запустить архив

1. Скачай [`project-archive/life-engine.zip`](project-archive/life-engine.zip) через GitHub: открой файл и нажми **Download raw file** (или скачай репозиторий целиком).
2. Распакуй архив.
3. Открой терминал в папке, где находится `index.html`.
4. Выполни: `python -m http.server 8000`.
5. Открой http://localhost:8000.
6. Не закрывай терминал, пока игра запущена.

Требуется Python для встроенного локального HTTP-сервера. Запуск двойным кликом по `index.html` не поддерживается, поскольку используются ES-модули и IndexedDB.
