# Текущее состояние проекта

Обновлено: 2026-10-29. Основано на аудите переданного архива LIFE ENGINE. Полноценный E2E-прогон в браузере не выполнялся.

## Статус исходников в GitHub

- На ветке `main` исходники приложения пока не лежат отдельными файлами: они находятся в `project-archive/life-engine.zip`.
- Поэтому обычный просмотр изменений, поиск по коду и CI в GitHub пока не охватывают приложение напрямую.
- Следующий блокирующий шаг: извлечь исходники в Git, сверить их с этой картой модулей и настроить базовые проверки. Отслеживается в [Issue #1](https://github.com/Glupozombie/life-engine/issues/1).
- ZIP проверен на целостность, а четыре JS-модуля — через `node --check`; это подтверждает целостность архива и синтаксис, но не подтверждает корректность логики или работу игры в браузере.

## Фактический стек
- HTML/CSS/JavaScript ES modules, без UI-фреймворка.
- Canvas 2D для мира и аналитических графиков.
- IndexedDB для локальных сохранений; в persistence предусмотрен fallback.
- index.html — DOM и подключения.
- css/style.css — интерфейс и визуальная тема.
- js/simulation.js — модель мира, организмы, признаки, шаги, среда, события.
- js/renderer.js — отрисовка, hit-testing, графики и дерево линий.
- js/persistence.js — локальное сохранение/загрузка.
- js/main.js — UI, игровой цикл, скорость, выбор организма, панели.
- package.json включает type: module; npm scripts и тесты в архиве не обнаружены.

## Запуск
Из корня проекта: python -m http.server 8000, затем открыть http://localhost:8000. Запуск через file:// не поддерживается из-за ES-модулей и IndexedDB.
