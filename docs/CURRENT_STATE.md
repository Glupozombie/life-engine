## Фактический стек

- HTML, CSS и JavaScript ES modules без UI-фреймворка.
- Canvas 2D для мира и аналитических графиков.
- IndexedDB для сохранений с fallback через localStorage.
- `package.json` содержит `"type": "module"`; внешних npm-зависимостей и scripts в нём нет.
- `tests/simulation.test.js` содержит базовые тесты ядра симуляции на встроенных `node:test` и `node:assert`.
- `.github/workflows/validate-archive.yml` настраивается для проверки исходников в Git, автоматических тестов и сохранённого ZIP.

## Запуск

Из корня репозитория:

```bash
python -m http.server 8000
```

Затем открыть `http://localhost:8000`. Запуск через `file://` не поддерживается из-за ES modules и IndexedDB.
