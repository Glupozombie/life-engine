# Стартовый промпт для Gemini — LIFE ENGINE

Продолжи разработку существующего проекта LIFE ENGINE, не создавай его заново.

GitHub: https://github.com/Glupozombie/life-engine

Сначала открой и прочитай `AGENTS.md`, `docs/SESSION_HANDOFF.md`, `docs/CURRENT_STATE.md`, `docs/ROADMAP.md`. Проверь актуальное дерево файлов и последние коммиты. Если эта среда не имеет доступа к GitHub или записи в репозиторий, прямо сообщи об этом; не имитируй работу с файлами.

Продукт — визуальная браузерная песочница искусственной жизни. Важны различимые организмы, поведение и форма которых связаны с наследуемыми признаками, конкуренция за ресурсы, мутации, размножение, адаптация, линии происхождения, понятные события и сохранение мира.

Состояние на момент подготовки: исходники ранее лежали в `project-archive/life-engine.zip`; GitHub Actions прошёл проверку целостности ZIP и синтаксиса JS. Это не подтверждает работу в браузере, сохранение после перезапуска или производительность. Сверь эти сведения с текущим репозиторием.

Если исходники ещё в ZIP:
- сначала изучи структуру архива;
- перенеси исходники в отдельные файлы Git, сохранив ZIP как резервную копию;
- не удаляй и не перезаписывай оригинал до проверки;
- настрой воспроизводимый запуск и автоматические проверки.
Если перенос уже сделан, не повторяй его: займись первым незавершённым приоритетом из handoff.

Не ограничивайся анализом: выполни одну конкретную задачу, проверь её и сохрани результат, если инструменты позволяют. Не переписывай проект целиком. После каждого завершённого этапа обновляй `docs/SESSION_HANDOFF.md` и фиксируй изменения в GitHub. Не откладывай сохранение на конец, поскольку лимит может закончиться внезапно.

Чётко помечай DONE / IN PROGRESS / NOT TESTED / BLOCKED. Не называй код протестированным, если запускалась только синтаксическая проверка. В конце дай краткий отчёт с файлами, коммитом, тестами и одним следующим шагом.
