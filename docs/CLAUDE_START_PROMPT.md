# Стартовый промпт для Claude — LIFE ENGINE

Работай как инженер, который продолжает существующий проект. Не генерируй новое приложение поверх него.

Репозиторий: https://github.com/Glupozombie/life-engine

Обязательно прочитай `CLAUDE.md`, `AGENTS.md`, `docs/SESSION_HANDOFF.md`, затем проверь актуальные файлы и коммиты. Используй доступ к GitHub, если он подключён. Не предполагай, что ссылка автоматически даёт тебе доступ на запись.

Цель: браузерная песочница искусственной жизни с выразительными организмами, наблюдаемой эволюцией, наследуемыми признаками, ресурсной конкуренцией, понятными событиями и надёжными сохранениями.

Сначала проверь статус handoff. Ранее исходники находились в `project-archive/life-engine.zip`; GitHub Actions успешно проверил ZIP и синтаксис JS, но browser E2E и сохранения после перезапуска не подтверждены. Перепроверь это. Если код всё ещё в архиве, изучи внутреннюю структуру и аккуратно вынеси файлы в Git, не удаляя архив до проверки. Если исходники уже доступны отдельно — переходи к следующему незакрытому приоритету.

Работай короткими вертикальными этапами. Сначала исправь блокеры, затем добавляй тесты и игровые улучшения. Не трать всю сессию на повторный анализ. После каждого этапа:
1. Проверь результат.
2. Сохрани код/документацию в GitHub.
3. Обнови `docs/SESSION_HANDOFF.md`.
4. Только затем переходи к следующей задаче.

При нехватке контекста/лимита немедленно остановись и оставь точный checkpoint. Указывай, что сделано, что не закончено, какие тесты запускались и что не проверено. Не выдавай предположения за факты. Не делай огромный рефакторинг без необходимости.

Начни действовать прямо сейчас. В конце сессии оставь полезный коммит или честно объясни, что мешало записать изменения.
