# Архитектура LIFE ENGINE

## Стек
HTML5, CSS, JavaScript ES modules, Canvas 2D, IndexedDB с fallback. В переданном архиве нет UI-фреймворка, сборщика или внешних runtime-зависимостей. Запуск: python -m http.server 8000.

## Карта файлов
| Файл | Ответственность |
|---|---|
| index.html | DOM, области симуляции, панели, подключения |
| css/style.css | Тема, сетка, панели, адаптивность и анимации |
| js/simulation.js | Модель мира/организмов/видов, признаки, ресурсы, шаг симуляции, среда, события |
| js/renderer.js | Canvas, формы организмов, hit-testing, графики и дерево происхождения |
| js/persistence.js | IndexedDB, сохранение/загрузка, слоты, форматирование времени |
| js/main.js | Инициализация UI, обработчики, игровой цикл, скорость, выбор, панели и связь модулей |
| package.json | Метаданные и type: module |

## Поток выполнения
1. main.js импортирует модель, renderer и persistence.
2. Создаётся или восстанавливается мир.
3. Игровой цикл вызывает шаги модели с выбранной скоростью.
4. Renderer рисует Canvas; UI обновляет сводку, события и лабораторию.
5. Состояние сохраняется локально; предусмотрен экспорт/импорт.

## Правила изменений
- Не дублировать расчёты модели в renderer или UI.
- Сохранять стек и границы модулей, если нет веской причины менять.
- Не добавлять React/Vite/WebGL/Worker без измеримой необходимости.
- При изменении формата мира обновлять версию и тестировать старые сохранения.
- Журнал должен опираться на реальные события.
- Новый наследуемый признак должен влиять на поведение/ресурсный баланс, если он не объявлен чисто визуальным.
