# Стартовый промпт для ChatGPT — LIFE ENGINE

Работай над существующим репозиторием, а не создавай проект с нуля.

Репозиторий: https://github.com/Glupozombie/life-engine

Сначала прочитай `AGENTS.md`, `docs/SESSION_HANDOFF.md`, `docs/CURRENT_STATE.md` и `docs/ROADMAP.md`. Проверь актуальные файлы и последние коммиты. Не считай старую документацию доказательством текущего состояния.

Твоя цель — начать разработку LIFE ENGINE: понятной визуальной песочницы искусственной жизни, где организмы отличаются формой и поведением, наследуют признаки, мутируют, конкурируют за ресурсы и эволюционируют по причинно-следственным правилам.

На момент написания этого промпта исходники были в `project-archive/life-engine.zip`; проверка ZIP и синтаксиса JS через GitHub Actions прошла, но полноценный запуск в браузере, сохранения после перезапуска и FPS не подтверждены. Сначала проверь, актуально ли это. Если код всё ещё в архиве — изучи его, вынеси исходники в отдельные файлы Git, сохранив ZIP до подтверждения запуска. Если перенос уже выполнен — не повторяй его.

**Не ограничивайся советами и планом. Начни выполнять первую безопасную задачу.** Если у тебя есть GitHub connector или доступ к инструментам записи, внеси изменения напрямую. Если нет — не утверждай, что коммит сделал; скажи об ограничении и предоставь готовые изменения.

Лимит может закончиться в любой момент:
- перед работой зафиксируй цель в `docs/SESSION_HANDOFF.md`;
- после каждого законченного этапа сохрани результат в GitHub и обнови handoff;
- не жди финального ответа, чтобы записать прогресс;
- при нехватке лимита останови новые задачи и оставь конкретный следующий шаг;
- разделяй DONE, IN PROGRESS, NOT TESTED и BLOCKED.

Запускай только реальные проверки. Успешный синтаксис не означает, что игра работает. Не переписывай всё приложение, не меняй стек без причины и не выдумывай результаты.

В конце укажи изменённые файлы и коммиты, реальные результаты проверок, ограничения и следующий шаг. Главный результат сессии — полезный код/проверка в репозитории и обновлённый handoff, а не длинный отчёт.
