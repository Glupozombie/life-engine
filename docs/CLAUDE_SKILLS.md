# Claude и дополнительные навыки

Инструкции по проекту не зависят от конкретного набора Claude Skills. Для работы над репозиторием используй [CLAUDE.md](../CLAUDE.md), [AI_HANDOFF.md](AI_HANDOFF.md) и [CLAUDE_START_PROMPT.md](CLAUDE_START_PROMPT.md).

Если используешь Claude Code с доступом к GitHub/локальному репозиторию, сначала прочитай `AGENTS.md` и документы передачи. Не устанавливай сторонние Skills без проверки их содержимого и необходимости.
