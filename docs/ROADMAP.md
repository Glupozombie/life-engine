# Дорожная карта LIFE ENGINE

Приоритеты основаны на архиве, переданном 2026-10-29. Сначала проверяй существующие механики, не переписывай уже реализованное.

## P0 — реальная проверка
- [ ] Пройти smoke-тест в браузере: запуск, пауза, скорости, среда, пища, выбор организма, события.
- [ ] Проверить сохранение, перезапуск, слоты, экспорт/импорт.
- [ ] Проверить нулевую популяцию, пустые ресурсы, предел численности, ошибочный импорт.
- [ ] Проверить консоль браузера и адаптивность.
- [ ] Записать реальные результаты в docs/TESTING.md.

## P1 — причинно-следственная модель
- [ ] Сценарно проверить наследование и мутации.
- [ ] Проверить стоимость скорости/размножения, расход энергии и влияние пищи.
- [ ] Убедиться, что журнал отражает реальные события и причины.
- [ ] Проверить линии происхождения, вымирание и восстановление мира.

## P2 — понятность новичку
- [ ] Проверить, что игрок понимает происходящее за первые 10 секунд.
- [ ] При необходимости добавить необязательное короткое обучение.
- [ ] Сделать обратную связь событий заметной, но не шумной.
- [ ] Проверить обычное разрешение и узкое окно.

## P3 — устойчивость
- [ ] Измерить FPS и длительность шага при обычной и максимальной популяции.
- [ ] Проверить рост памяти и истории при длительном прогоне.
- [ ] Добавить тесты чистой логики симуляции.
- [ ] Проверить миграцию сохранений.

Пункт считается завершённым только после конкретной проверки с результатом в docs/TESTING.md. Написанный код сам по себе не является доказательством работоспособности.
