## Ручной smoke-тест
Отмечай PASS только после выполнения в браузере.
- [ ] Запустить python -m http.server 8000, открыть http://localhost:8000.
- [ ] Создать мир и убедиться, что организмы двигаются.
- [ ] Проверить паузу/продолжение и каждую скорость.
- [ ] Добавить пищу и проверить реакцию.
- [ ] Сменить среду и проверить UI.
- [ ] Выбрать организм; проверить карточку и клики по пустой области.
- [ ] Дождаться рождения/смерти и проверить журнал.
- [ ] Сохранить мир, обновить вкладку, загрузить слот.
- [ ] Экспортировать мир и импортировать его в другой слот.
- [ ] Проверить повреждённый JSON и сохранность предыдущего сейва.
- [ ] Проверить вымирание, максимальную численность и длительный ускоренный прогон.
- [ ] Проверить консоль браузера.
