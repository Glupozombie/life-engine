## Автоматическая проверка архива в GitHub Actions

Workflow: `.github/workflows/validate-archive.yml`.
- Проверяет ZIP через `unzip -t`.
- Распаковывает архив во временный каталог и запускает `node --check` для каждого найденного JS-файла.
- Проверка workflow: ожидает выполнения в GitHub Actions; пока результат не просмотрен, не считать CI подтверждённым.
- Ограничение: синтаксис не доказывает корректность логики, работу Canvas/IndexedDB или корректность UI в браузере.
