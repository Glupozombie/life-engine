# Claude — инструкции для LIFE ENGINE

Перед работой прочитай AGENTS.md, docs/CURRENT_STATE.md и docs/ROADMAP.md. Для изменений игрового опыта открой docs/PROJECT_BRIEF.md; для подробного рабочего процесса используй docs/IMPLEMENTATION_PROMPT.md.

Работай с существующим проектом, а не генерируй его заново. Сначала проверь актуальные файлы и команды. Документация не важнее фактического кода.

- Не переписывай стек без конкретной причины.
- Понятная симуляция важнее количества графиков.
- Не выдумывай функции, причины событий и результаты тестов.
- Делай небольшие связные изменения, запускай доступные проверки.
- В конце перечисли изменения, реальные проверки, ограничения и следующие шаги.
- После значимого этапа синхронизируй docs/CURRENT_STATE.md, docs/TESTING.md и docs/CHANGELOG.md.
