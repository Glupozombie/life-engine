# Примеры GENESIS

Здесь размещаются небольшие воспроизводимые экспериментальные материалы, а не старые примеры LIFE ENGINE.

## Что добавлять
- JSON-конфигурации коротких PPO запусков с seed и параметрами.
- Обезличенные snapshot телеметрии: observation, activations, weights, body state.
- Сценарии MuJoCo/Gymnasium: начальная поза → действие → ожидаемое физическое событие.
- Сравнения baseline и обученной policy с численными метриками.
- Скриншоты интерфейса с подписью того, что именно проверяется.

Каждый пример должен содержать дату, commit, команды воспроизведения, ожидаемый результат и статус проверки. Не сохраняй checkpoints, большие логи или случайные временные файлы в Git без отдельного обоснования.

Старые изображения/референсы интерфейса предыдущего проекта не являются спецификацией GENESIS.
