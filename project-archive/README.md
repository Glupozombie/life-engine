# Архивы проекта

Архивы здесь — временное хранилище/контрольные копии. Основным источником истории разработки должны стать отдельные исходные файлы в Git, а готовые ZIP-релизы лучше публиковать через GitHub Releases.

## Реестр архивов

### `life-engine.zip`
- **Расположение:** [project-archive/life-engine.zip](life-engine.zip)
- **Назначение:** исходный снимок приложения, переданный 2026-10-29; используется для восстановления исходников до переноса в обычные файлы репозитория.
- **Проверка:** ZIP прошёл проверку целостности; `node --check` прошёл для `simulation.js`, `renderer.js`, `persistence.js` и `main.js` на Node.js v22.16.0.
- **Не проверено:** браузерный E2E, восстановление сейва после перезапуска, FPS/память.
- **Важно:** не удалять архив, пока исходники не извлечены в Git и не подтверждены запуском и проверками.

## Правила
- Не коммить секреты, токены, пользовательские данные, кэши и зависимости.
- Перед заменой или удалением архива проверить, что он не является единственной копией нужного состояния.
- Для каждого нового архива указывать дату, назначение и способ проверки.
