# Архивы проекта

Эта папка предназначена для небольших текстовых заметок об архивах и правилах хранения, а не для постоянного хранения тяжёлых ZIP-сборок.

## Рекомендации
- Исходный код и история изменений должны храниться в Git.
- Большие ZIP-архивы, готовые сборки и контрольные версии лучше публиковать через GitHub Releases или внешнее хранилище.
- Для каждого архива указывать дату, commit SHA, назначение и способ проверки.
- Не добавлять в архив секреты, токены, пользовательские данные, кэши и зависимости.
- Перед заменой или удалением архива проверить, что он не является единственной копией нужного состояния.

## Реестр архивов
Пока архивы не зарегистрированы.
